## TP 1 - Découverte de l'environnement

### Commandes utilisées

- pwd
- whoami
- hostname
- cat /etc/os-release
- uname -a

### Ce que j'ai appris

- Comment connaître mon dossier courant.
- Comment identifier l'utilisateur connecté.
- Comment connaître le nom de la machine.
- Comment identifier la version de Linux.
- Comment afficher les informations du noyau Linux.
- Commande | Fonction                  
`pwd`     Où suis-je ?              
`ls`      Que contient ce dossier ? 
`cd`      Se déplacer               
`cd ..`   Remonter d'un niveau      
`mkdir`   Créer un dossier          
`touch`   Créer un fichier          
`cat`     Lire un fichier           
`echo`    Afficher du texte         
`>`       Écrire/remplacer          
`>>`      Ajouter                   
`cp`      Copier                    
`mv`      Déplacer/renommer         
`rm`      Supprimer
